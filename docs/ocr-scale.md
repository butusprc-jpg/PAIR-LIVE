# OCR scale reading — work 5/8

Tesseract CLI (English, page segmentation 7) reads real PNG frames after an ImageMagick ROI crop, grayscale conversion, contrast stretch and despeckle. The OCR adapter is separate from `CameraControl.tsx`. Its output keeps raw OCR text, normalized display text, confidence and crop. The pure parser accepts one unsigned number with an optional decimal point. It takes the final displayed digit from the string, never from a rounded float. Ambiguous text is rejected.

`FrameSource` carries frame ID, round ID, source type, timestamp, original PNG bytes, dimensions and health. `MOBILE_CAMERA` is the planned LiveKit source type, but this repository currently has no authenticated publisher and no server-side LiveKit egress/frame extraction. Therefore **no production frame adapter is active**. Do not treat the browser's same-tab DEMO camera as server evidence. IP camera, NVR/DVR and cloud camera (including Hik-Connect) implement the same interface later, through an authenticated gateway that timestamps frames server-side. No RTSP/Hik-Connect integration was tested.

Default verification requires 5 distinct, fresh frames at least 100 ms apart, each no more than 4 seconds old; confidence at least 75, blur score at least 1 and glare fraction at most 0.25. Every normalized display must match. The thresholds are in `defaultOcrConfig`; production calibration against a real scale and lighting is still required. A frozen frame, blur, glare, low confidence, multiple readings or camera loss leads to REVIEW_REQUIRED. Majority voting is not used. OCR starts only for SCANNING after the close timestamp; an OPEN or SETTLED round cannot commit. The current public confirmation endpoint always returns 403 because admin authentication is unavailable. No server worker writes a result, settles a round or announces a result yet.

`EvidenceStorage` accepts immutable object keys derived from SHA-256. `LocalEvidenceStorage` creates files exclusively; an object-storage implementation can replace it. Migration `003_ocr_evidence.sql` adds result metadata and immutable evidence references, with original/crop hashes, OCR text and timestamps. It does not store base64 images. Do not enable result settlement before authenticated admin review, transaction-safe state transition, evidence persistence, and event outbox (`ROUND_SETTLED`, `OCR_REVIEW_REQUIRED`, `WORKER_ERROR`) are wired and integration-tested.

Fixture tests use generated PNG images of scale displays and invoke real Tesseract/ImageMagick. They verify OCR recognition separately from mocked frame-quality/state tests. Blur and glare transformed PNG fixtures exercise image quality metrics, while frame sequence tests use mocks. These fixtures are synthetic and do not establish accuracy on a physical scale, mobile camera, LiveKit stream or glare/blur images. No database integration test ran without `DATABASE_URL`.
