# ตั้งค่า LINE OA สำหรับ PAIR LIVE V1.1

1. สร้าง LINE Login Channel และ LIFF App ใน LINE Developers โดยตั้ง LIFF Endpoint URL เป็น `https://your-domain.example/` (HTTPS) และ Scope `profile`, `openid` ตามการใช้งาน LIFF SDK เดิม หน้าเว็บส่ง **access token** ให้ `/api/auth/line` เพื่อตรวจ channel, expiry และ profile กับ LINE ฝั่งเซิร์ฟเวอร์ ไม่รับ user ID จากเบราว์เซอร์เป็นหลักฐานตัวตน LIFF SDK จัดการ redirect/state/nonce ของ Login; แอปไม่มี callback endpoint แยก หาก LINE Console ต้องระบุ callback ให้ใช้ HTTPS LIFF Endpoint เดียวกันตามการตั้งค่า Channel และตรวจค่าจริงบน Console ก่อนเปิดใช้งาน
2. ตั้ง `NEXT_PUBLIC_LINE_LIFF_ID`, `LINE_LOGIN_CHANNEL_ID` และ `LINE_LOGIN_CHANNEL_SECRET` ตาม `.env.example` โดย Channel ID/Secret นี้เป็นของ **LINE Login** เท่านั้น ตั้ง `ADMIN_AUTH_ORIGIN`, allowlist ฝั่งเซิร์ฟเวอร์ และ Admin Auth migration แยกต่างหาก; สิทธิ์ผู้ดูแล OA ไม่กลายเป็นสิทธิ์แอดมินของแอปอัตโนมัติ
3. เชื่อม LINE OA กับ Messaging API Channel ของ OA นั้น ตั้ง `LINE_MESSAGING_CHANNEL_ID`, `LINE_MESSAGING_CHANNEL_SECRET` และ access token ของ Messaging API แยกจาก Login Channel ตั้ง Webhook URL เป็น `https://your-domain.example/api/line/webhook` แล้วทดสอบ Verify ใน LINE Console Webhook ตรวจ HMAC-SHA256 จาก raw body และบันทึก event ID แบบไม่ซ้ำ ไม่ใช้ event เป็น Login
4. ไฟล์ [Rich Menu template](../assets/line/rich-menu.template.json) ใช้ LIFF URL `https://liff.line.me/REPLACE_LIFF_ID` สามปุ่ม; เปลี่ยน ID ก่อนติดตั้ง ภาพต้นแบบคือ [rich-menu.png](../assets/line/rich-menu.png) มี PNG 2500×1686 ให้ตรวจพื้นที่กดบนเครื่องจริง ปุ่มติดต่อแอดมินส่งข้อความกลับเข้าแชต OA ไม่เปิดธุรกรรมหรือส่งผลรอบ
5. **ยังไม่ติดตั้ง Rich Menu หรือแก้ OA จริง** ต้องขออนุมัติการเปลี่ยน OA แยกต่างหาก ตรวจลิงก์บน LINE Android/iOS, login ครั้งแรก/ครั้งถัดไป, session expiry, wallet และประวัติด้วยบัญชีทดสอบที่ได้รับอนุญาตก่อนเผยแพร่

ไม่มี LINE credentials ในสภาพแวดล้อมนี้ การ Login, webhook delivery, rich menu จริง และข้อความ OA จริงยัง **NOT TESTED** Settlement ยัง BLOCKED จึงไม่มีการประกาศผลที่ยังไม่ยืนยัน โมดูลแจ้งเตือนเดิมเป็นเส้นทางเดียวสำหรับ event; ไม่เพิ่ม queue ใหม่
